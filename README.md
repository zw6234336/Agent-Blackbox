# Agent-Blackbox

一个原生 macOS 保险决策助手原型，用来把保单、条款和费率信息整理成面向个人用户的保障分析、缺口推荐和产品对比体验。

## 当前产品方向

- 面向个人与家庭的保障决策，而不是工程化监控后台
- 首页先展示保障结论、主要缺口和下一步行动
- 用结构化条款与费率信息支撑分析结果和推荐解释
- 按家庭成员查看已有保单、保障责任和待补风险
- 提供基础版 / 均衡版 / 加强版三档推荐方案
- 只保留少量候选产品，突出适配原因与限制条件

## 核心页面

1. **总览**：家庭保障分、主要缺口、行动建议、资料完整度
2. **我的保障**：按成员查看保单、责任覆盖、保障期间与来源说明
3. **保障分析**：按风险维度展示覆盖率、目标保额和缺口金额
4. **缺口推荐**：先给结论，再解释为什么缺、缺多少、该怎么补
5. **产品对比**：对比候选产品的责任亮点、限制条件和适配原因

## 设计原则

- 导航更少，围绕个人决策闭环组织内容
- 多用卡片、摘要、进度和建议，少用密集表格
- 强调“多花多少钱，换来什么保障提升”
- 每个结论都能追溯到条款摘要、费率信息或家庭资料
- 视觉上采用更温和的个人产品风格，而非企业控制台风格
